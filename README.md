# 분좋느좋 카페

바다가 보이는 3층짜리 웹 3D 카페예요. 지금 접속한 사람들과 같은 공간에서 걷고, 앉고, 말을 걸 수 있어요.
카페 건물 간판의 이름은 **해변가**예요.

**바로 들어가기:** https://jiyoo0209.github.io/online-cafe-project/

## 층별 공간
- **1F 카운터 · 바다 데크:** 바리스타에게 메뉴 주문, 창가 바, 바다 쪽 야외 데크
- **2F 오션뷰 라운지:** 소파, 책장, 턴테이블(누르면 음악 켜기/끄기), 돌아다니는 고양이
- **3F 루프탑 테라스:** 줄전구, 파라솔, 선베드, 불멍 화로, 망원경

## 조작
- 바닥을 누르면 걷기, 의자나 소파를 누르면 앉기
- 드래그로 둘러보기, 휠이나 두 손가락으로 확대·축소
- PC에서는 WASD 또는 방향키로 걷기, Enter로 말하기

## 구성
- `index.html` 파일 하나로 되어 있어요. 3D는 three.js r128을 써요.
- 실시간 접속은 Supabase Realtime이 맡아요.
  - Presence: 접속자 목록, 이름, 외형
  - Broadcast: 위치, 앉기, 말풍선, 손 흔들기, 들고 있는 음료
- 위치는 움직일 때만 초당 2~3번 보내요. 가만히 있을 때는 9초마다 한 번만 보내서 무료 플랜 한도 안에서 돌아가요.
- 캐릭터 외형은 숫자 하나(seed)로 정해져요. 그래서 모든 사람의 화면에 같은 모습으로 보여요.

## 참고
- Supabase 무료 프로젝트는 1주일 동안 활동이 없으면 일시정지돼요. 그러면 Supabase 대시보드에서 프로젝트를 다시 켜면 돼요.
- `index.html`에 들어 있는 Supabase 키는 웹페이지용 공개(anon) 키예요. 노출되어도 괜찮아요.
